⛰️ Heaps

Trees stored in arrays; priority queues.

Heap: a tree stored in an array

A min heap is a complete binary tree where every parent is at most its children, so the smallest sits at the root (access is O(1)). Built from 30, 12, 70, 44, 15, 55.

For index i: parent is floor((i-1)/2), left child 2i+1, right child 2i+2. Delete the root by moving the last node up, then heapify down.
